## Model Overview

d1 is a decision model from Liquid AI: instead of generating text it reads text and images and returns typed answers — yes/no, choice, score — with calibrated probabilities, **in one forward pass with no output tokens**. It is built for classification, routing, scoring, moderation, visual inspection and LLM-as-judge checks. Context window is 32,768 tokens.

It speaks the same `/v1/decisions` wire as [Jev](../TypeSafe/jev.md), so the request shape is identical and you can swap one for the other by changing `model`.

{% hint style="info" %}
d1 also judges for the [D1 Router](../../text-models-llm/Liquid-AI/d1-router.md), which uses it to decide how hard each chat request is and route accordingly.
{% endhint %}

Every key you send under `questions` comes back under `answers` with the matching type.

Two things to notice if you are coming from Jev:

* **`output_tokens` is `0`.** d1 reaches its answer in a single forward pass rather than emitting tokens, so the whole cost is the input. The call above billed $0.00001 and returned in 369 ms.
* **Probabilities are full precision.** d1 returns values like `0.9724147137760725` where Jev rounds to two decimals. Round them yourself before showing them to anyone.
